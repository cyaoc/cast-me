# Keep the Medium Contract scoped to identity evidence

A Deformation Tier locked for a drawn request decides what the medium can express, but the gates downstream of it never read that result: Shot Direction offered photographic body-cutoff options a two-and-a-half-head figure cannot distinguish, and Reference Coverage asked for full-body evidence the same tier had already discarded. The Medium Contract gains one authority in response — evidence it records as unavailable in this medium is never requested as missing reference evidence. It deliberately does not grow into a general production contract recording which non-identity dimensions remain meaningful, because option vocabulary belongs to the gate that owns it, and Shot Direction already carries a rule to adapt its options to current locks that only needed to name the tier.

Making that authority fire required one addition. Visible Body Evidence is a category parallel to Protected Identity Cues, judged separately by Identity Review, so it never reaches a channel state and a rule phrased only over closed channels stayed inert for the exact case that motivated it. The contract therefore records a Visible Body Evidence carriage state — carried, simplified, or not carried — beside the per-cue channel states. Body evidence is identity evidence, so this stays inside the boundary this decision draws, and the tier gradient already computed the value; recording it only puts the result where a downstream gate can read it.

## Consequences

Suppression is judged per recorded state, never per body region. A tier that stops carrying the figure still permits asking about shoes, stance, and weight placement, and characteristic wardrobe is weighted up as a recognition channel precisely when structural channels close, so those questions matter more at strong deformation rather than less.

Only Reference Coverage reads the carriage state. Identity Review is unchanged: at the shortest proportion it already switches to deciding completion through transferred cues and thumbnail-silhouette readability, so it does not depend on the new state.
