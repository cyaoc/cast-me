# Teach the style vocabulary through the result, not the brief

The six drawn style axes are production vocabulary, and a beginner cannot name a rendering treatment before seeing one; asking someone to choose line weight and shading-layer count from text descriptions before the first image puts the whole cost on the person least able to pay it. CastMe therefore delivers a Style Readout with the first result of each style state — the locked axis values, Deformation Tier, and stylization intensity in visible language — instead of eliciting them up front, which also makes the existing single-axis Scoped Option Refresh reachable for the first time.

Two alternatives were rejected. Promoting a supplied style-reference image to a first-class path fails the common case, which is one photograph of a person and no second image the user could produce on request. A cheap low-quality style probe contradicts the final-asset rule, and the readout combined with single-axis refresh already gives the same iteration loop at full quality.

## Consequences

The readout reports locked decisions, not the rendered result. Whether the image actually matches them stays with Identity Review and its Uneven Stylization check, so the readout never becomes a second, weaker quality claim.
